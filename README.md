# ВетПетри — научная песочница чашки Петри 🧫

Учебный симулятор бактериальной чашки Петри для пар по (ветеринарной) микробиологии.
Один HTML-файл, без бэкенда и ключей. Играбельно в браузере, воспроизводимо по seed,
модели сверены тестами на известных кривых.

**Онлайн**: https://shray77.github.io/vetpetri/

## Что внутри (модели, которые узнает микробиолог)

| Слой | Модель | Параметры и источник |
|---|---|---|
| Субстрат | сетка 128×80, диффузия (Нейман) + расход на рост | D — эффективные, усл. |
| Рост | Моно μ·S/(Ks+S) + лаг-фаза по Бараньи–Робертс (q/(1+q)) | μmax 2.1 ч⁻¹ (td 20 мин), Ks 4 мг/л — Monod 1949; обзор Kovárová-Kovar & Egli 1998 |
| Конкуренция | общая ёмкость ячейки (эксплуатационная, родня Лотки–Вольтерры) | Nmax = 10⁸ КОЕ/ячейка — калибровка |
| Антибиотик | Хилл/Emax time-kill: kill = kmax·A^H/(A^H+C50^H), C50 автокалиброван так, что net-рост = 0 при A = MIC | kmax ≈ 3 ч⁻¹, H ≈ 1.2 — Regoes 2004, Nielsen & Friberg 2006; β-лактамы убивают делящиеся |
| Резистентность | окно селекции (MIC…MPC), мутационный поток wt→R | Drlica & Zhao 2003/2007; MPC = 8×MIC (оценка для β-лактамов) |
| Патогены | E. coli, Salmonella Dublin, Pasteurella multocida, E. coli R (β-лактамаза TEM-типа) | MIC по CLSI/EUCAST (для Salmonella — прокси по ампициллину); PK: t½ амоксициллина у КРС ≈ 1 ч (Kreil 2012) |

## Эксперименты-пресеты

1. **Кривая роста** — лаг → экспонента → плато → отмирание; баланс массы.
2. **Конкуренция видов** — E. coli против Salmonella Dublin за общий субстрат.
3. **Time-kill: одна доза** — лог-линейный спад и регроу после падения A ниже MIC.
4. **Окно селекции мутантов** — при дозе между MICwt и MPC резистентные вытесняют wt (100% R);
   выше MPC мутанта — подавлены оба.
5. **Песочница** — посев каплями, капли антибиотика, стирание; градиент вокруг капли = живое окно селекции.

## Честные упрощения

Нет иммунитета, биоплёнок, горизонтального переноса генов, хозяина и метаболизма лекарства
в тканях. Рост на плоскости; расширение колоний — эффективная подвижность (фронт
Кольмогорова–Фишера), не жгутики. Скорость мутаций демо-завышена (~10⁻⁶/деление против
~10⁻⁹–10⁻¹⁰/п.н. в реале; резистентность чаще приходит извне/горизонтально).
Единицы субстрата условные. **Не для клинических решений.**

## Архитектура и разработка

```
src/engine.js   — чистый движок: параметры+seed на входе, состояние на выходе (typed arrays)
src/tests.js    — тесты на известных кривых (S-кривая, time-kill, seed, окно селекции)
src/ui.js       — интерфейс (Canvas-рендер, пресеты, графики)
src/style.css, src/index-template.html
build.js        — инлайнит всё в один корневой index.html
```

```bash
node src/tests.js   # тесты моделей (node)
node build.js       # пересборка single-file index.html
```

Фиксированный seed (mulberry32) + фиксированный порядок обхода = воспроизводимый запуск.
Слой Web Worker не подключён (не нужен на сетке 128×80); WASM не используется.
