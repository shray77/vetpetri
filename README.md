# ВетПетри — научная песочница чашки Петри 🧫

Учебный симулятор бактериальной чашки Петри для пар по (ветеринарной) микробиологии.
Один HTML-файл, без бэкенда и ключей. Играбельно в браузере, воспроизводимо по seed,
модели сверены тестами на известных кривых.

**Онлайн**: https://shray77.github.io/vetpetri/

## Что внутри (модели, которые узнает микробиолог)

| Слой | Модель | Параметры и источник |
|---|---|---|
| Субстрат | сетка 128×80, диффузия (Нейман) + расход на рост | D — эффективные, усл. |
| Рост | Моно μ·S/(Ks+S) + лаг-фаза по Бараньи–Робертс (q/(1+q)) | μmax 2.1 ч⁻¹ (td 20 мин), Ks 4 мг/л — Monod 1949; обзор Kovárová-Kovar & Egli 1998 |
| Конкуренция | общая ёмкость ячейки (эксплуатационная, родня Лотки–Вольтерры) | Nmax = 10⁸ КОЕ/ячейка — калибровка |
| Антибиотик | Хилл/Emax time-kill: kill = kmax·A^H/(A^H+C50^H), C50 автокалиброван так, что net-рост = 0 при A = MIC | kmax ≈ 3 ч⁻¹, H ≈ 1.2 — Regoes 2004, Nielsen & Friberg 2006; β-лактамы убивают делящиеся |
| PK-режимы введения | одна суточная доза: 1 болюс / 3 введения (q8h) / инфузия 24 ч; бейдж %T>MIC | цель fT>MIC 40–70% для β-лактамов — Berry 2022; болюс vs инфузия — Tilanus 2023; t½ амоксициллина КРС ≈ 1 ч — Kreil 2012 |
| Мега-чаша | статические полосы АБ 0 → 1× → 10× → 100× MICwt | Baym 2016 (Science, Kishony lab, «Giant Petri Dish»; уроки — HHMI BioInteractive) |
| Персистеры | дормантный компартмент n↔p (детерминированно, без ГСЧ); β-лактам на дормант не действует | Balaban 2004 (Science 305:1622): WT a=1.2·10⁻⁶ ч⁻¹, b=0.1 ч⁻¹; hipQ a=10⁻³ ч⁻¹, b≈10⁻⁴ (сводка Kussell & Leibler 2005) |
| Резистентность | окно селекции (MIC…MPC), мутационный поток wt→R | Drlica & Zhao 2003/2007; MPC = 8×MIC (оценка для β-лактамов) |
| Патогены | E. coli, Salmonella Dublin, Pasteurella multocida, E. coli R (β-лактамаза TEM-типа) | MIC по CLSI/EUCAST (для Salmonella — прокси по ампициллину); PK: t½ амоксициллина у КРС ≈ 1 ч (Kreil 2012) |

## Эксперименты-пресеты

1. **Кривая роста** — лаг → экспонента → плато → отмирание; баланс массы.
2. **Конкуренция видов** — E. coli против Salmonella Dublin за общий субстрат.
3. **Time-kill: режим введения** — та же суточная доза болюсом / q8h / инфузией;
   бейдж T>MIC: почему для β-лактама «лечит» капельница, а не жирный болюс.
4. **Окно селекции мутантов** — при дозе между MICwt и MPC резистентные вытесняют wt (100% R);
   выше MPC мутанта — подавлены оба.
5. **Песочница** — посев каплями, капли антибиотика, стирание; градиент вокруг капли = живое окно селекции.
6. **Мега-чаша: лестница доз** — полосы 0→1×→10×→100×MIC; мутант прорывает зоны ступенчато,
   wt упирается в первую (эволюция в реальном времени, как у Baym 2016).

## Для пары и лабы

- **Хроника событий** — панель под графиками пишет всё, что случилось и когда: конец лаг-фазы,
  исчерпание субстрата, «АБ выше/ниже MIC», рождение первого мутанта, прорыв R-фронта в полосу
  мега-чаши, регроу; ручные действия (посев, капля АБ, болюс) тоже записываются.
- **Сценарий для пары** — раскрывашка у каждого пресета: шаги → вопрос студентам → вывод.
- **Проектор-режим** — крупный шрифт и контраст одним кликом (шапка → «Проектор»).
- **Экспорт CSV/PNG** — история КОЕ и чаша для отчёта по лабе.
- **Ссылка-сценарий** — вся настройка (пресет, доза, режим, seed, виды) сериализуется в URL-hash;
  студент открывает ссылку из методички и получает готовый эксперимент.
- **Probe** — курсор над чашей: концентрация АБ (в ×MIC), субстрат, состав популяции в точке.
- **Виды — галочками, без сброса** — галочка сразу ставит вид на чашу (если его не было —
  сеется капля в свободный слот), снятие скрывает вид, не останавливая прогон; «Посев»
  выключенным видом включает его автоматически.
- **Тесты моделей: 9/9** — S-кривая, time-kill, seed, окно селекции, PK-инфузия,
  мега-чаша, CSV/hash, хроника, персистеры.
- **Слои чаши** — «Клетки / Субстрат / Антибиотик / Рост μ»: теплокарты того, что под колориями;
  слой «Рост μ» показывает, где net-скорость положительная (зелёный), где ноль (граница = MIC) и где гибель (красный).
- **PD-профиль (Emax)** — график чистой скорости роста vs концентрации АБ: ноль кривой = MIC
  по построению, пунктир — голодная зона (β-лактам бьёт делящиеся — голодные выживают ниже MIC).
- **Челлендж-карточки** — у каждого пресета 2 карточки «предскажи → проверь» (e-Bug style).
- **Персистеры** — селектор «выкл / дикий тип / hipQ-мутант»: дормантный резервуар переживает
  летальную дозу и восстанавливает популяцию после падения АБ ниже MIC (время-kill с «хвостом»);
  в пресете 3 включены по умолчанию (WT).

## Честные упрощения

Нет иммунитета, биоплёнок, горизонтального переноса генов, хозяина и метаболизма лекарства
в тканях. Рост на плоскости; расширение колоний — эффективная подвижность (фронт
Кольмогорова–Фишера), не жгутики. Скорость мутаций демо-завышена (~10⁻⁶/деление против
~10⁻⁹–10⁻¹⁰/п.н. в реале; резистентность чаще приходит извне/горизонтально).
Единицы субстрата условные. **Не для клинических решений.**

## Архитектура и разработка

```
src/engine.js   — чистый движок: параметры+seed на входе, состояние на выходе (typed arrays)
src/tests.js    — тесты на известных кривых (S-кривая, time-kill, seed, окно селекции,
                  PK-инфузия, мега-чаша, CSV/hash, хроника, персистеры)
src/ui.js       — интерфейс (Canvas-рендер, пресеты, графики, экспорт, hash, проектор)
src/style.css, src/index-template.html
build.js        — инлайнит всё в один корневой index.html
```

```bash
node src/tests.js   # тесты моделей (node)
node build.js       # пересборка single-file index.html
```

Фиксированный seed (mulberry32) + фиксированный порядок обхода = воспроизводимый запуск.
PK-слои (dosing), полосы мега-чаши и персистеры детерминированы и не трогают поток rng() —
хэши старых сценариев совпадают с v1.0 (персистеры по умолчанию выключены). Слой Web Worker
не подключён (не нужен на сетке 128×80); WASM не используется.
